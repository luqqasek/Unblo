# Native PixelSeal region screen

Declared before results, 2026-11-22. Goal: improve the #3188 PixelSeal branch, especially native tiny rectangles, without using GT at inference. This is one new model fit and final evaluation, not full OOF. Two GPUs on one node; no other user's jobs touched.

Fresh learned local RGB/luminance/chroma filters, exact JND, delayed stride-4 features; no batch/spatial normalization. A region MLP pools feature means, second moments, surrounding-ring statistics and geometry. Two outputs learn physical region coverage and box IoU. Known bits are used only for exact unchanged synthetic embedding, not a mandatory decoder-recovery gate. No resized raw candidate crops.

Original outer fold: 113 train / 57 developmental validation. Split the 113 into 90 new-specialist training and 23 inner calibration by seed8831. Generate four attempted native clean-region pairs per training real source and three per inner-calibration source; regions must be wholly clean at native GT512. Mix 256 public train-source pairs with these. Public dev sources are separated into 64 calibration and64 audit sources. Never generate from outer validation or test images. Real generated/edited clean content and public photographs remain separate strata. Extra crops/messages are not extra source identities.

Original embedder, strength, raw256 payload and exact uint8 quantization unchanged. Native crops only, no post-embedding image resampling or photometric augmentation. Both twins share all content and geometry. Training receives 8 synthetic paired views plus4 real images per optimizer update across two GPUs. One AdamW/OneCycleLR, maxLR3e-4, EMA0.99, clip1.0, up to800 updates /18minutes training including gates. Input, first projection, integral statistics and loss are FP32; deeper layers BF16. Pipeline must pass arithmetic and gradient checks before launch.

Native coordinate rectangle grid uses widths/heights3–80 on128 grid, area24–820, AR<=16, position step2cells, then independent edge refinement by1cell. Training uses random candidates, jittered GT and hard negatives; every100 steps mines the whole search on a clean training view. Search returns one coherent rectangle; apply OR only if existing base predicted foreground <=10%. Thus this first specialist does not explicitly carve holes. Larger/irregular predictions retain the best existing base unless a small addition is accepted.

At updates200/400 report held-out known-region pair AUC and within-image real GT-box ranking (diagnostic only). Stop at400 if pair AUC remains<0.55; this is a screening decision, not an information-theoretic bound. Final inference runs the exact same GT-free search on inner23 and outer57. Choose threshold using inner23 official mean per-image two-class mIoU, with no-op winning ties. A test candidate requires >=0.005 overall gain, improved tiny-region FG IoU and no>0.01 regression in clean IoU on WM>50%. Report all buckets and paired image-bootstrap intervals. The base saw inner23 during its old training; this calibration limitation is retained, while the new specialist does not see them during fitting. Reused outer fold is development evidence, not independent test performance.

Preserve checkpoints, all selected predictions and existing #3188 submission. Do not submit a failed or unchanged candidate. Official leaderboard0.8 is an aspiration, not an expected score from this protocol.
