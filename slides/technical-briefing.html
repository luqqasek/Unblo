Unblo / Task 1 / Problem and design

Watermark localization: both classes matter

Given an image, watermark family and embedded message, predict which pixels contain the watermark.

The task

  • Input: 512 × 512 RGB image. Output: 128 × 128 binary mask.
  • 510 labeled training images: 170 per family, covering PixelSeal, TrustMark and StegaStamp.
  • The score averages intersection-over-union for watermarked and clean pixels.

The observation that shaped the method

Some images have a small marked region. Others are mostly watermarked with small clean holes. A model must handle both geometries.

We used separate partial-watermark and clean-hole heads, class-balanced supervision and an IoU-oriented loss.

Illustration: predicting “watermark everywhere” on a 98% marked image gives 98% pixel accuracy, but completely misses the clean region.

If asked why accuracy is insufficient: “A majority-class prediction can look accurate while missing the region that matters. We optimize for overlap of both classes.”
Sources: Task 1 README, DINO training01 / 10

Unblo / Task 1 / Architecture and adaptation

Pretrained visual features plus watermark evidence

DINOv2 segmentation branch

A pretrained vision transformer supplies features from several layers. A convolutional decoder combines them with a local image branch to predict spatial masks.

Frozen: original DINO weights.
Trained: LoRA updates in attention, feature projections, local branch and segmentation decoder.

LoRA adds a small low-rank update to an existing weight matrix. It lets us adapt pretrained features with fewer trainable parameters.

The selected ensemble uses a rank-32 member and a family-conditioned member. Separate family channels account for different watermark traces.

PixelSeal specialist

The specialist combines multiscale image features, local residual information and agreement between decoded bits and the known watermark message.

For PixelSeal, the final probability map combines:

p = 0.70 pensemble + 0.30 pspecialist

TrustMark and StegaStamp keep the selected frozen ensemble outputs. The baseline predicted coverage routes between hole and partial heads.

If asked why DINO can help: “It provides spatial context. Local processing and message agreement provide additional signals specific to the watermark.”

Unblo / Task 1 / Training data and augmentation

More geometries, then a focused decoder update

Real images and synthetic pairs

DINO training uses the official labeled images. The specialist training also uses cached clean / watermarked image pairs to generate masks with known support.

The synthetic sampler produces 50% clean-hole examples, 25% locally embedded crops and 25% full-image watermark remnants.

The selected PixelSeal precursor uses batches of 24 synthetic + 8 real examples, and an exponential moving average of weights (EMA).

The archived source-preparation pipeline specifies COCO train2017. The exact external image count in the selected checkpoint is not established by the final package. Pretrained weights are a separate source of prior knowledge.

Final refinement: Feature CutMix

Freeze the feature extractor. Train only the last prediction head on cached 166-channel feature maps.

Feature CutMix: swap a rectangular feature region between examples and swap the matching mask region. This varies context and boundaries while keeping supervision aligned.

Also use rotations, flips, feature dropout and crops biased toward the minority class.

85 fit / 28 selection / 57 reused development images. AdamW, LR 2e−4, weight decay 0.05. Selected update: step 200, with 191,745 changed parameters. Logit gain 8 adjusts output sharpness.

If asked what is new in the final edit: “A decoder-only update with feature-space mixing. It adds no new backbone and does not establish a statistically reliable local gain.”
Sources: synthetic sampling, training, final protocol03 / 10

Unblo / Task 1 / Loss and mask selection

Pixel supervision and overlap optimization

L = 0.50 balanced BCE + 0.25 Lovász(watermark) + 0.25 Lovász(clean)

Why these three terms?

Balanced binary cross-entropy: average errors separately for the two classes. A tiny clean hole gets a meaningful contribution even when the watermark dominates.

Watermark Lovász: a differentiable surrogate related to IoU, encouraging the marked region to overlap the target.

Clean Lovász: applies the same objective to the complementary class, protecting clean-region overlap.

These are two loss families, with Lovász applied symmetrically. We do not have a component-by-component ablation proving each term’s final contribution.

Turning probabilities into a mask

  1. Sort pixels by predicted watermark probability.
  2. Consider marking the top k pixels.
  3. Estimate the two-class IoU using expected intersection and union counts.
  4. Choose the best region size k.

This is a ratio-of-expectations approximation, rather than exact expected IoU. The final PixelSeal path uses it after blending. It is post-processing, not another training loss.

If asked why not threshold at 0.5: “A fixed threshold treats pixels independently. Our final decision accounts for the region-level metric and both classes.”

Unblo / Task 3 / Problem and constraints

Unlearning with no labeled retain set

What we had

An original ViT-B/16 image classifier and 3,500 unlabeled images to forget.

The classifier produces one logit per class. Softmax converts these scores into class probabilities.

We freeze the original model as a teacher and initialize a trainable student from the same weights.

For each image, the teacher’s highest-scoring class becomes a pseudo-label. It can be wrong because we have no true labels.

What success required

The evaluator compares exact and altered forget images against retrained reference models, and applies a hidden 70% accuracy gate.

We had no gold-model outputs, labeled control images or genuine retain set for directly measuring this objective.

Early token-drop distillation barely changed predictions and scored zero. Simple class suppression also scored zero.

That motivated image-specific soft targets and explicit preservation constraints. Simply making all forget predictions wrong would not reproduce a retrained model.

If asked where the labels came from: “Directly from the original classifier’s argmax. They identify the class whose confidence we control. The training target is a modified probability distribution.”
Sources: task and method, pseudo-label construction, early experiments06 / 10

Unblo / Task 3 / Constructing forgetting targets

We designed the target confidence distribution

Teacher evidence sets the ordering

  1. Evaluate each image and 28 transformed views with the original classifier.
  2. Measure log-odds of its pseudo-class against all other classes.
  3. Combine the ranked original margin and ranked average margin across views, then rank that combined signal.
  4. Assign higher target confidence to images with stronger teacher evidence.

Confidence and transformation sensitivity are proxies. They do not directly measure how much the model memorized an image.

Our chosen distribution sets the values

δ* = −3 + 6.5 Φ−1(u)
p*(pseudo-class) = sigmoid(δ*)

u is the image’s fractional rank. Φ−1 converts that rank into a normal-distribution quantile. δ* is target log-odds.

The location −3 and spread 6.5 are selected parameters. They do not come from a retrained gold model.

At the median rank, δ* = −3, giving about 4.7% target probability. Higher-ranked images can retain much more confidence. The method does not guarantee a decrease for every image.

If asked where the forgetting distributions came from: “The teacher supplied an ordering. We imposed a chosen log-odds distribution on that ordering. These are heuristic surrogate targets.”
Source: hardness_v2, nscore and target_v207 / 10

Unblo / Task 3 / Soft targets and preservation data

Keep class relationships while changing confidence

How the full target is assembled

We set the pseudo-class probability using its target log-odds. For the other classes, we average teacher logits over mild views and apply a temperature of 1.5.

We normalize over those other classes, then allocate the remaining probability mass according to their relative preferences.

Illustrative example: target “cat” probability is 20%. The teacher prefers “dog” over “fox” at 3:1 among the alternatives. The target becomes cat 20%, dog 60%, fox 20%.

This avoids replacing the remaining distribution with arbitrary or uniform probabilities. Ordinary cross-entropy on the original argmax would instead reinforce that class.

Where preservation examples come from

Final E50 uses only the supplied forget images and original checkpoint. No external natural-image anchors or synthetic image bank enter the selected training.

Strong crops, color changes, rotations and optional CutMix create surrogate preservation views. We ask the student to match the teacher on these views.

Working hypothesis: preserve useful representation and behavior beyond the exact image. These views remain derived from the forget set. They are not an independent retain set and cannot prove retained utility.

If asked whether we are preserving the same data: “There is a deliberate tension: change exact and mild-view predictions, while constraining drift on strong views. The separation is approximate.”
Sources: rdist_v2 / target_v2, view generation, selected configuration08 / 10

Unblo / Task 3 / Loss and optimization

Forgetting targets and preservation losses

L = KLtarget + 2 Llog-odds + 5 KLanchor + 10 LCLS

What each term does

Target KL: match the student’s output distribution to the constructed soft target.

Log-odds loss: Smooth L1 between student and target pseudo-class log-odds, controlling the desired confidence.

Anchor KL: match teacher outputs on strong transformed / mixed views.

CLS loss: squared distance between unit-normalized teacher and student CLS vectors. The CLS token summarizes the image for classification.

KL terms average temperatures 1 and 2. Different loss scales mean 10 versus 5 does not imply twice the importance.

The selected training recipe

Frozen teacher, all student weights trainable. 2,500 AdamW updates, learning rate 6e−5, warmup and cosine decay, gradient clipping at 1.0.

Each forget batch has 16 exact + 16 mildly altered images. A separate batch has 32 strong preservation views.

Mild transforms include crops, flips, color changes, noise and blur. Their target pseudo-class logit gets an extra reduction of 1.

E50 uses feature-preservation weight 10. Weight-distance regularization, conflict projection and synthetic-bank replacement are disabled.

If asked why preserve features as well as outputs: “Similar probabilities can conceal internal representation changes. CLS matching adds a direct constraint on that representation.”
